# slides/

발표용 슬라이드 (최종본).

## Files

- **`slides_native.pptx`** — 발표용 native PowerPoint. 28 slides.
- **`slides_native.pdf`** — 슬라이드 PDF export.

## 빌드

마크다운 원본은 `../docs/slides.md`. 이를 편집 가능한 pptx로 빌드하려면:

```bash
python ../src/plotting/build_editable_pptx.py
# → slides_editable.pptx (구조 편집용, 최종본 아님)
```

native pptx는 위 스크립트 출력 + 수동 디자인 보정으로 생성되었다.
